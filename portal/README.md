# MongDee Portal

หน้าเว็บหลัก (landing page) ใช้เป็นทางเข้าไปยังแดชบอร์ดของสองโปรเจค:

- **MongDee** — AI Booth OS (วิเคราะห์พฤติกรรมลูกค้าหลายกล้อง)
- **MongDee Mini Kiosk** — ระบบสแกนสินค้าหน้าร้าน

หน้านี้เป็นไฟล์ static ล้วน (`index.html` / `style.css` / `script.js`)
ไม่ต้องมี backend ของตัวเอง — เครื่อง AI หลักของทั้งสองโปรเจคยังรันอยู่ที่
เครื่องเดิมเหมือนเดิม หน้านี้แค่เก็บ "ลิงก์แดชบอร์ด" ของแต่ละโปรเจคไว้ใน
`localStorage` ของเบราว์เซอร์ แล้วพาไปเปิดเมื่อกดปุ่ม

## วิธีใช้

1. เปิด `index.html` โดยตรง (ดับเบิลคลิก) หรือ serve ด้วยเว็บเซิร์ฟเวอร์ static
   เช่น `python -m http.server 5500` แล้วเข้า `http://127.0.0.1:5500/`
2. กด **ตั้งค่า** ที่การ์ดของแต่ละโปรเจค ใส่ลิงก์แดชบอร์ดสาธารณะ แล้วกด
   **บันทึกลิงก์**
3. จุดสถานะ (ออนไลน์ / เข้าถึงไม่ได้) จะตรวจสอบซ้ำทุก 20 วินาทีโดยอัตโนมัติ

## ทำให้เข้าถึงแดชบอร์ดได้จากอินเทอร์เน็ต (จำเป็นก่อนตั้งค่าลิงก์)

ลิงก์ที่ใส่ในหน้านี้ต้องเป็น URL ที่เข้าถึงได้จริงจากอินเทอร์เน็ต — ไม่ใช่
`127.0.0.1` ของเครื่องหลัก เพราะเบราว์เซอร์ของผู้ชมอยู่คนละเครื่อง

### MongDee

ระบบพร้อมอยู่แล้ว 2 ทาง (เลือกทางใดทางหนึ่ง):

- **Vercel** (แนะนำสำหรับดูระยะไกลตลอดเวลา) — deploy ตาม
  `../MongDee/docs/vercel-deployment.md` แล้วใช้ URL ที่ Vercel ให้มา
  (เช่น `https://your-app.vercel.app/`)
- **Tunnel ชั่วคราว** — รัน `../MongDee/run_web.bat` (เปิดแอปที่ `:8000`) แล้ว
  รัน `../MongDee/run_public_dashboard.bat` (พร็อกซี read-only ไปที่ `:8090`)
  จากนั้นเปิด tunnel เช่น `cloudflared tunnel --url http://127.0.0.1:8090`
  แล้วใช้ URL ที่ได้ต่อท้ายด้วย `/dashboard`

### MongDee Mini Kiosk

- รัน `../MongDee-kiosk/start.bat` (เปิดแอปที่ `:8000`) แล้วรัน
  `../MongDee-kiosk/start-public-dashboard.bat` (พร็อกซี read-only ไปที่
  `:8091`) จากนั้นเปิด tunnel เช่น
  `cloudflared tunnel --url http://127.0.0.1:8091` แล้วใช้ URL ที่ได้
  ต่อท้ายด้วย `/dashboard`

พร็อกซีทั้งสองตัว (`dashboard_proxy.py` ของแต่ละโปรเจค) เปิดให้เฉพาะ
คำขอ GET ของหน้าแดชบอร์ดเท่านั้น — ควบคุมกล้อง แก้ไข/ลบข้อมูล ทำผ่าน
พร็อกซีนี้ไม่ได้

## Deploy หน้า Portal นี้เองให้เปิดได้จากทุกที่ (ทางเลือก)

ถ้าต้องการให้ตัวหน้า Portal เองก็เข้าถึงได้จากทุกที่โดยไม่ต้องเปิดไฟล์บน
เครื่องนี้ ให้ deploy โฟลเดอร์นี้ไปที่บริการ static hosting เช่น Vercel
หรือ GitHub Pages ได้ทันที (ไม่มี build step) — ลิงก์ที่ตั้งค่าไว้จะถูก
เก็บแยกกันในแต่ละเบราว์เซอร์ที่เข้ามาเปิด ต้องตั้งค่าลิงก์อีกครั้งในเครื่อง
ที่เข้ามาดูใหม่

# การติดตั้งและสร้างตัวเปิดแอป (Installer / Build Guide)

## ทำไมไม่ใช่ .exe ไฟล์เดียวที่รวมทุกอย่าง?

โปรเจกต์นี้ใช้ PyTorch + CUDA + OpenCV + Ultralytics ซึ่งติดตั้งแล้วหนักรวมกัน **9GB**
(ไลบรารี NVIDIA CUDA อย่างเดียวก็ ~5GB) การอัดทุกอย่างลงไฟล์ .exe เดียวจะได้ไฟล์ขนาด
หลาย GB สร้างช้ามาก และเปราะบาง (CUDA โหลดไดนามิกจากไฟล์ข้างเคียง ใส่ในไฟล์เดียวมักพัง)
ทุกซอฟต์แวร์ AI ระดับเดียวกัน (เช่น ComfyUI, Automatic1111) ก็ไม่ทำแบบนั้นเช่นกัน —
ใช้วิธี "ตัวติดตั้งขนาดเล็ก + สภาพแวดล้อม Python แยกต่างหาก" แทน ซึ่งเป็นแนวทางที่ใช้ที่นี่
เช่นกัน:

1. **`launcher.py`** — หน้าต่างเดียว กดปุ่มเปิดบูธ/Dashboard/Trainer/**เว็บเบราว์เซอร์**
   แทนการพิมพ์คำสั่ง — ตัวมันเองใช้แค่ PySide6 (เบา ไม่ต้องพึ่ง PyTorch) จึงคอมไพล์เป็น
   .exe/binary ได้เล็กและเร็ว
2. **`install.sh` / `install.bat`** — ตัวติดตั้งจริง สร้าง Python virtual environment
   (`.venv/`) แยกจาก Python หลักของเครื่อง แล้วติดตั้งไลบรารีหนัก (PyTorch ฯลฯ) ที่นั่น
   พร้อมสร้างทางลัดเปิดแอป
3. **`build_linux.sh` / `build_windows.bat`** — คอมไพล์ `launcher.py` ให้เป็นไฟล์
   execuTABLE/`.exe` แบบ standalone (ด้วย PyInstaller) — ได้ไฟล์เดียวเบา ๆ (~80-100MB
   จาก PySide6) ดับเบิลคลิกเปิดได้ทันทีแม้เครื่องไม่มี Python ติดตั้ง ตัวมันจะพาไปรัน
   `install.sh`/`install.bat` ให้เองถ้ายังไม่เคยติดตั้ง

## วิธีที่ 1: ติดตั้งแบบเร็วที่สุด (แนะนำ)

**Linux:**
```bash
bash install.sh          # รุ่น CPU ใช้ได้ทุกเครื่อง (แนะนำ)
bash install.sh --gpu    # รุ่นเร่งความเร็วด้วย NVIDIA GPU (ต้องมีการ์ดจอ NVIDIA + driver)
```
เสร็จแล้วเปิดแอปได้จาก `./run_launcher.sh` หรือค้นหา "MONGDEE AI Booth OS" ในเมนู
Applications (สร้างทางลัดให้อัตโนมัติ)

**Windows:**
```bat
install.bat          REM รุ่น CPU ใช้ได้ทุกเครื่อง (แนะนำ)
install.bat --gpu    REM รุ่นเร่งความเร็วด้วย NVIDIA GPU
```
เสร็จแล้วเปิดแอปได้จากไอคอนบน Desktop "MONGDEE AI Booth OS" หรือรัน `run_launcher.bat`

ทั้งสองวิธีนี้ **ต้องมี Python 3.10+ ติดตั้งไว้ก่อน** (ดาวน์โหลดจาก python.org) แต่ไม่ต้องรู้
วิธีใช้ command line เลย — สคริปต์ทำให้ทุกอย่างอัตโนมัติ

## วิธีที่ 2: ไฟล์ .exe/binary ตัวเปิดแอป (ไม่ต้องพิมพ์คำสั่งเลยแม้แต่ครั้งแรก)

ถ้าต้องการให้ผู้ใช้ปลายทาง **ดับเบิลคลิกไฟล์เดียวเปิดได้เลยโดยไม่ต้องเปิด terminal**
แม้แต่ในการติดตั้งครั้งแรก ให้สร้างตัวเปิดแอปแบบ standalone ก่อนแจกจ่าย:

**Linux** (สร้างและทดสอบแล้วจริงบนเครื่องนี้ — ได้ไฟล์ 83MB รันได้ปกติ):
```bash
bash build_linux.sh
# ได้ไฟล์ dist/MONGDEE-AI-Booth-OS
```

**Windows** (ต้องรันบนเครื่อง Windows จริง — PyInstaller ไม่รองรับข้าม OS):
```bat
build_windows.bat
REM ได้ไฟล์ dist\MONGDEE-AI-Booth-OS.exe
```

จากนั้นคัดลอกไฟล์ที่ได้ (`MONGDEE-AI-Booth-OS` หรือ `.exe`) ไปวางไว้ที่**โฟลเดอร์เดียวกับ
app.py** (โฟลเดอร์รากของโปรเจกต์) แจกจ่ายทั้งโฟลเดอร์ไปพร้อมกัน — ตัวเปิดแอปหาตำแหน่งไฟล์อื่น
ๆ จากตำแหน่งของตัวเองเสมอ ผู้ใช้ปลายทางดับเบิลคลิกไฟล์นี้ได้ทันที: ถ้ายังไม่เคยติดตั้งจะขึ้น
ปุ่ม "🔧 ติดตั้งระบบครั้งแรก" ให้กดครั้งเดียว (รันสคริปต์ install.sh/install.bat ให้อัตโนมัติ
พร้อม log ให้ดู) ครั้งต่อไปเปิดมาจะพร้อมใช้งานทันที

> **ข้อควรรู้**: ไฟล์ที่ build ได้ *ไม่ได้รวม* PyTorch/OpenCV/YOLO ไว้ในตัว (ตามเหตุผลด้านบน)
> — มันเป็นแค่ "ตัวเปิด + ตัวติดตั้ง" ที่สวยงาม สภาพแวดล้อมจริงยังถูกสร้างแยกที่ `.venv/`
> เหมือนวิธีที่ 1 ทุกประการ เพียงแต่ผู้ใช้ไม่ต้องเห็น command line เลยตลอดกระบวนการ

## ไม่อยากสร้าง .exe เลย? ใช้เบราว์เซอร์แทนได้

ถ้าเครื่องปลายทางมีแค่เบราว์เซอร์ (เช่น แท็บเล็ตหน้าบูธ) ไม่จำเป็นต้องสร้างหรือติดตั้ง .exe
ใด ๆ เลย — รัน `python web_server.py` บนเครื่องที่ต่อกล้อง (หลัง `install.sh`/`install.bat`
เสร็จแล้ว) หรือกดปุ่ม **"🌐 เปิดผ่านเบราว์เซอร์"** ใน `launcher.py` แล้วเปิด URL ที่ขึ้นมาจาก
เบราว์เซอร์เครื่องไหนก็ได้ในวง LAN เดียวกัน ไม่ต้องติดตั้งอะไรเพิ่มบนอุปกรณ์ที่ใช้ดู — ดู
รายละเอียดที่ README.md หัวข้อ "ใช้งานผ่านเบราว์เซอร์"

## สรุปไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|------|---------|
| `launcher.py` | หน้าต่างเปิดแอป (ปุ่ม เปิดบูธ/Dashboard/Trainer + ปุ่มติดตั้งครั้งแรก) |
| `install.sh` / `install.bat` | สร้าง `.venv/` + ติดตั้งไลบรารี + สร้างทางลัด |
| `build_linux.sh` / `build_windows.bat` | คอมไพล์ `launcher.py` เป็น standalone executable/.exe |
| `assets/icon.png` / `assets/icon.ico` | ไอคอนแอป ใช้ทั้งใน .desktop, shortcut .lnk, และไฟล์ .exe |
| `run_launcher.sh` / `run_launcher.bat` | สร้างอัตโนมัติโดย install script — เปิด launcher ผ่าน venv ที่ถูกต้อง |

## ทดสอบแล้วจริงบนเครื่องนี้

- `build_linux.sh` → ได้ไฟล์ `dist/MONGDEE-AI-Booth-OS` (83MB) รันจริงได้ ตรวจพบ `.venv`
  ถูกต้องเมื่อวางที่โฟลเดอร์โปรเจกต์ และแสดงปุ่มเปิดบูธ/Dashboard/Trainer ครบ
- `install.sh` รันจริงในสภาพแวดล้อมแยกต่างหาก (venv ใหม่, ไม่แตะของเดิม) — สร้าง venv,
  ติดตั้ง PyTorch (CPU), OpenCV, Ultralytics, PySide6 ฯลฯ และสร้างทางลัดสำเร็จ
- `build_windows.bat` **ทดสอบรันจริงบน Windows แล้ว** (PyInstaller `--onefile --windowed`)
  → ได้ไฟล์ `dist\MONGDEE-AI-Booth-OS.exe` (~44MB) เปิดจริงได้ทันที เปิดเป็นหน้าต่าง
  "MONGDEE AI Booth OS — Launcher" ครบทุกปุ่ม เมื่อคัดลอกไปวางที่โฟลเดอร์โปรเจกต์
  (โฟลเดอร์เดียวกับ `app.py`/`.venv`) จะตรวจพบว่าติดตั้งแล้วอัตโนมัติ (ขึ้น "✅ ระบบพร้อมใช้งาน"
  ทันที ไม่ต้องกดติดตั้งซ้ำ) — วางไว้ใน `dist/` เฉย ๆ (ไม่ย้ายออกมา) จะขึ้น "ยังไม่ได้ติดตั้งระบบ"
  เพราะหา `.venv` ที่อยู่คนละโฟลเดอร์ไม่เจอ ตามที่อธิบายไว้ด้านบน
- `install.bat` เขียนตามมาตรฐาน Windows ที่ถูกต้อง (ยังไม่ได้ทดสอบรันแยกจาก `.venv` ที่มีอยู่ก่อน
  บนเครื่องนี้ เพราะเครื่องนี้ตั้งค่า `.venv` ไว้แล้ว) — หากพบปัญหาเมื่อรันจริงแจ้งได้ จะแก้ไขให้

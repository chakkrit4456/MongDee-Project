# คู่มือการใช้งาน MONGDEE MINI KIOSK

คู่มือติดตั้งและรันแบบสั้น ๆ ตั้งแต่เปิดเครื่องจนใช้งานได้ (รายละเอียดเชิงลึก
ดู [README.md](README.md), การตั้งค่าความเสถียร/ทดสอบดู [STABILITY.md](STABILITY.md))

## 1. ข้อกำหนดเบื้องต้น

- Windows
- Python 3.10 ขึ้นไป (ถ้ายังไม่มี ติดตั้งจาก [python.org](https://www.python.org/downloads/)
  หรือ `winget install Python.Python.3.11`)
- กล้อง USB ต่อกับเครื่อง (ไม่มีกล้องก็รันได้ ดูหัวข้อ 5)
- อินเทอร์เน็ต **เฉพาะตอนติดตั้งครั้งแรก** เท่านั้น (โหลดไลบรารี + โมเดลจำแนกภาพ
  ~10MB) หลังจากนั้นใช้งานได้แบบออฟไลน์เต็มรูปแบบ

## 2. รันครั้งแรก

ดับเบิลคลิก `start.bat` ที่โฟลเดอร์นี้ ระบบจะทำให้อัตโนมัติ:

1. สร้าง virtual environment (`backend\venv`)
2. ติดตั้งไลบรารีทั้งหมดจาก `backend\requirements.txt`
3. เปิดเซิร์ฟเวอร์ที่ `http://127.0.0.1:8000`

ครั้งแรกอาจใช้เวลาสักครู่ (ติดตั้ง + ดาวน์โหลดโมเดล) รอจนเห็นข้อความว่าเซิร์ฟเวอร์
เริ่มทำงานแล้วค่อยเปิดเบราว์เซอร์

## 3. วิธีรันปกติ (ครั้งถัดไป)

ดับเบิลคลิก `start.bat` แล้วเปิดเบราว์เซอร์ไปที่:

```
http://127.0.0.1:8000/
```

กด **F11** เพื่อดูแบบเต็มจอสำหรับจอแสดงผลหน้าบูธ

### หน้าเว็บที่ใช้งานได้

| หน้า | ใช้ทำอะไร |
|---|---|
| `/` | จอแสดงผลหลักหน้าบูธ (สแกนสินค้าสด) |
| `/products` | โชว์สินค้าทั้งหมดแบบ grid ให้ลูกค้ากดดูเอง |
| `/enroll` | เพิ่มสินค้าใหม่เข้าระบบ (พนักงาน) |
| `/manage` | แก้ไข/ลบสินค้าที่มีอยู่ |
| `/dashboard` | รายงานยอดสแกน สินค้ายอดนิยม ช่วงเวลาคนเยอะ |
| `/calibrate` | ปรับความไวกล้อง + บันทึกภาพพื้นเปล่า (ทำก่อนใช้งานจริงเสมอ) |

**ก่อนใช้งานจริงครั้งแรกที่หน้างาน** ต้องไปที่ `/calibrate` แล้วกด
"บันทึกภาพพื้นเปล่า" ขณะที่แท่นหมุนว่างเปล่าก่อนเสมอ — ระบบอื่นทั้งหมด (ตรวจจับ
การวางสินค้า, การตัดพื้นหลังตอนแมตช์) อ้างอิงจากภาพนี้

ให้อุปกรณ์อื่นในร้าน (มือถือเจ้าของร้าน) เข้าดู `/dashboard` ผ่าน Wi-Fi วงเดียวกัน
ได้ด้วย โดยเปลี่ยน `HOST` ใน `backend/app/config.py` จาก `127.0.0.1` เป็น `0.0.0.0`
แล้วรันใหม่

## 4. เพิ่มสินค้าเข้าระบบ

ไปที่ `/enroll` → วางสินค้าบนแท่นหมุน → ระบบถ่ายภาพหลายมุมให้อัตโนมัติ (แท่นหมุน
หมุนของมันเองตลอดเวลา) → เลือกภาพที่ชัด (อย่างน้อย 3 ภาพ) → กรอกชื่อ/ราคา/รายละเอียด
→ บันทึก ใช้สแกนได้ทันทีไม่ต้องเทรนโมเดลใหม่

## 5. รันแบบไม่มีกล้อง (ทดสอบ/พัฒนา)

ดับเบิลคลิก `start-fake.bat` แทน — ใช้กล้องจำลองแทนกล้องจริง จำลองแท่นหมุนว่าง/มี
สินค้าได้ สลับฉากได้ที่ `http://127.0.0.1:8000/dev/fake-camera`

## 6. เปิดให้เข้าถึงแดชบอร์ดจากภายนอกร้าน (ไม่บังคับ)

โปรเจคนี้มีหน้า [MongDee Portal](../portal/README.md) เป็นทางเข้าไปยังแดชบอร์ดของ
ทั้ง MongDee และ MongDee Mini Kiosk จากที่ไหนก็ได้ ขั้นตอนสำหรับ kiosk:

1. เปิด `start.bat` ทิ้งไว้ (แอปหลักที่ `:8000`)
2. เปิด `start-public-dashboard.bat` อีกหน้าต่าง (พร็อกซีแบบอ่านอย่างเดียวไปที่
   `:8091` — เปิดให้เฉพาะหน้ารายงาน คุมกล้อง/แก้ไขข้อมูลผ่านทางนี้ไม่ได้)
3. เปิด tunnel ออกอินเทอร์เน็ต เช่น
   `cloudflared tunnel --url http://127.0.0.1:8091`
4. เอา URL ที่ได้ (ต่อท้ายด้วย `/dashboard`) ไปตั้งค่าในหน้า Portal

## 7. รหัสผ่านผู้ดูแล (Admin PIN)

การลบสินค้า/รูป/วิดีโอ ต้องใส่ PIN (4–12 หลัก) ครั้งแรกที่กดลบจะให้ตั้ง PIN เอง
ลืม PIN ให้รันคำสั่งนี้จากโฟลเดอร์ `MongDee-kiosk`:

```
backend\venv\Scripts\python.exe backend\scripts\reset_admin_pin.py
```

แล้วตั้ง PIN ใหม่ตอนกดลบครั้งถัดไป

## 8. รันชุดทดสอบ (สำหรับนักพัฒนา)

```
cd backend
venv\Scripts\python.exe -m unittest discover -s tests -v
```

ไม่ต้องมีกล้องหรืออินเทอร์เน็ต

## 9. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `[Errno 10048]` / พอร์ตถูกใช้อยู่แล้ว | มีเซิร์ฟเวอร์ค้างอยู่ที่ `:8000` — ปิดหน้าต่าง `start.bat` เดิมก่อน หรือรัน `Get-NetTCPConnection -LocalPort 8000 -State Listen \| Select OwningProcess` แล้ว `Stop-Process` PID นั้น |
| กล้องไม่ขึ้น / `camera_open: false` | ตรวจว่าไม่มีโปรแกรมอื่นใช้กล้องอยู่ (Zoom/Teams), ลองเลือกกล้องใหม่ที่ `/calibrate`, หรือใช้ `start-fake.bat` แทนระหว่างทดสอบ |
| ตรวจจับสินค้าไม่แม่น / ไวเกินไป | ไปปรับที่ `/calibrate` — ดูหัวข้อ "On-site calibration" ใน README.md |
| ติดตั้งครั้งแรกช้า/ค้าง | ต้องมีอินเทอร์เน็ตตอนติดตั้งครั้งแรกเท่านั้น (โหลดไลบรารี + โมเดล ~10MB) |
